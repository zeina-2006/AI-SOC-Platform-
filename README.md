# AI SOC Platform

A Python-based Security Operations Center platform built with FastAPI.

## Features
- Security event collection
- Brute-force detection
- Risk scoring and severity classification
- Security alerts and dashboard
- Automated tests with pytest

## Technology Stack
Python 3.12, FastAPI, SQLAlchemy, SQLite, Uvicorn, Pytest.

## Run the Application
```bash
python -m pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Run Tests
```bash
python -m pytest -v
```
